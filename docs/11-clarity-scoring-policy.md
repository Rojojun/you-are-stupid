# 질문 명확도 점수 정책

점수는 문장 길이나 특정 키워드 수를 세는 단일 규칙이 아니다. 먼저 발화 의도를 분류한
뒤, 의도 유형에 맞는 기준을 적용한다.

| 발화 유형 | 점수 원칙 |
| --- | --- |
| 진행 확인·교정·재개·쉬운 설명·규칙 재고지·대화 전달 | 의도가 분명하면 80점대. 작업 목표를 반복해서 쓰지 않았다고 감점하지 않음 |
| 메타 질문·평가 기준 확인 | 직전 결과나 기준을 가리키면 80점대 |
| 생산적 작업 요청 | 목표 30%, 맥락 20%, 제약 15%, 검증 15%, 완료 기준 20% |
| 모호한 새 요청 | 대상과 원하는 결과를 식별할 수 없을 때만 낮은 점수 |
| 욕설 포함 발화 | 명확도 점수와 분리. 욕설은 마찰 반응 신호로만 기록 |

중앙 엔진과 로컬 기준선은 같은 정책을 사용하며, 점수 규칙이 바뀔 때 엔진 버전을 올려
이전 snapshot을 자동으로 폐기한다. 대표 케이스는 `server/clarity-calibration.test.mjs`로
고정한다.
