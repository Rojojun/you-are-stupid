# 1. 제품 범위와 사용자 흐름

## 문제 정의

AI 코딩 도구를 여러 개 쓰면 기록은 흩어지고, “일을 한 시간”과 “에이전트를 바로잡은 시간”이 섞인다. 이 제품은 감시 도구가 아니라 사용자가 자신의 협업 방식을 돌아보는 개인 분석 도구다. 따라서 결과는 사람의 능력 점수나 생산성 순위가 아니라, 재작업·대기·전달·설명 요청의 패턴과 개선 추세를 보여 준다.

## 대상과 첫 출시 범위

| 구분 | v1 포함 | v1 제외 |
| --- | --- | --- |
| 운영체제 | macOS, Windows 11 | Linux, 모바일 |
| AI 도구 | Codex, Claude Code, Antigravity의 동의 기반 읽기/가져오기 | 키 입력 감시, 화면 녹화, 모든 앱 자동 수집 |
| 기록 | 질문, AI 응답, 시간, 토큰/모델 등 획득 가능한 메타데이터 | 획득 불가능한 토큰의 추정값을 실제값처럼 표시 |
| 분석 | 세션 분류, 감정/마찰 신호, 주·월 추세 | 직원 감시, 인사 평가, 타인 비교·랭킹 |
| 저장 | 원문, 축약문, 구조화 이벤트 | 기본 원문 클라우드 백업 |

## 핵심 사용자 흐름

1. 사용자가 로컬 앱을 설치하고 기기 암호화 키를 만든다.
2. 지원 도구별로 수집 범위를 고른다: `로컬 원문만`, `요약+이벤트 동기화`, `원문 포함 동기화`.
3. 수집기는 새 대화 또는 가져온 기록을 정규화하고 원문·요약·메타데이터를 분리 저장한다.
4. 중앙 분석은 세션 전체를 기준으로 활동 유형, 마찰 원인, 사용자 반응을 분류한다.
5. 대시보드는 비율, 대표 근거, 시간에 따른 변화, “다음번에 줄일 수 있는 마찰”만 보여 준다.
6. 사용자는 언제든지 원문 열람, 항목 정정, 동기화 중단, 특정 세션/전체 삭제, 내보내기를 할 수 있다.

## 표시할 분석 결과

- 활동 비율: 실제 작업, 에이전트 교정, 진행 확인, 대화 전달, 재개 지시, 쉬운 설명 요청, 규칙 재고지, 기타.
- 마찰 흐름: 오류 주장, 범위/모델 무단 변경 의심, 대기, 반복 지시, 욕설/강한 부정 표현의 발생 전후.
- 질문 성장: 목표 명확성, 맥락 제공, 제약 명시, 검증 요청, 후속 의사결정의 다섯 축 추세.
- 신뢰도: 각 분류에 `높음/보통/낮음`과 근거 이벤트를 함께 표시한다. 낮은 신뢰도는 사용자가 수정할 수 있다.

## 비기능 요구사항

- 원문은 기본값으로 기기 밖으로 나가지 않는다.
- 오프라인에서도 로컬 탐색과 보관이 가능해야 한다.
- 수집 실패는 사용자 작업을 막지 않고 재시도 대기열로 남는다.
- 대시보드는 점수로 사용자를 낙인찍지 않고, 근거와 기간 필터를 제공해야 한다.
